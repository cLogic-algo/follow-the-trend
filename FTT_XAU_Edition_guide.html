GRID
POSITION AVERAGING (AVERAGING DOWN)
WHAT IS GRID?
Grid opens additional positions in the same direction when price moves AGAINST the base position. Lowers the average entry price (for BUY) or raises it (for SELL). Allows closing the basket in profit even if price hasn't returned to the original entry.
⚠ Grid is a high-risk strategy during strong counter-trends — it can significantly increase exposure. Always set SL or Max Basket Loss.
GRID MODES
PriceDistance — Grid opens when price moves away by Grid Price Step ($) from the last grid level (or base). Simplest mode, purely based on price distance.
ReEntryTrigger — Grid waits for a trigger signal (MA4Cross/EMA) AND the required price distance. More selective — doesn't open on every move.
Off — Grid disabled. Bot trades single positions without averaging.
PARAMETERDEFAULTDESCRIPTION
Grid Max Levels20Maximum number of grid levels (excluding base). Bot won't open more even if price continues.
Grid Price Step ($)2.0Distance from last level to open the next. For XAU/USD this is dollars per ounce.
Grid Level Martingale Multiplier2.0Distance multiplier between consecutive levels. 2.0 = each next level is 2x further. 1.0 = fixed distance.
No Grid on Same CandleYesBlocks grid on the same candle as the previous level. Prevents multiple entries on one candle.
GRID VOLUME
STEP — Each grid level = Base Lot + (Grid Step Volume × level_number).
Example: Base=0.02, Step=0.02 → Grid_1=0.04, Grid_2=0.06, Grid_3=0.08...
MARTINGALE — Each level = Base Lot × (Martingale Multiplier ^ level_number).
Example: Base=0.02, Multi=2 → Grid_1=0.04, Grid_2=0.08, Grid_3=0.16... HIGH RISK!
FIX LOT — Every grid level has identical volume to the base position (Main Lot Size). Simplest and safest in terms of volume.
GRID PROTECTION — RECOVERY PAUSE
When a basket closes at a loss — bot pauses opening new grid levels for N candles. Gives the market time to settle before averaging again.
PARAMETERDEFAULTDESCRIPTION
Recovery Pause Candles0Number of candles to pause after a loss-closing basket. 0 = no pause (standard behaviour).
💡 Recovery Pause works independently for Buy and Sell. A loss on Buy does not block Sell grid.
PYRAMID
POSITION SCALING (SCALING IN)
WHAT IS PYRAMID?
GRID (averaging DOWN)
Price goes AGAINST you → new positions lower → lowers average → TP closer
PYRAMID (scaling UP)
Price goes WITH you → new positions higher → more volume on a winning trend
PYRAMID MODES
TPSL — Bot divides the Entry→TP range into equal (or martingale) segments and opens pyramid levels as price reaches each segment. Each new level moves the SL of previous levels to the entry price of the previous level (trailing SL).

RISK MANAGEMENT
CAPITAL PROTECTION
SOFT STOP LOSS (BASKET)
Bot calculates the volume-weighted average entry price of the whole basket and sets SL for every position at Grid Step × SL Multiplier distance from that average. SL moves automatically as new levels are added.
PARAMETERDEFAULTDESCRIPTION
Main Lot Size (Base)0.01Base position volume and reference point for grid/pyramid volume calculations. Minimum: 0.01.
Max Lot Size10.0Hard limit — no bot position will exceed this volume.
Soft SL Multiplier (x Grid Step)200SL = avg entry ± (Grid Price Step × this multiplier). Example: Step=$2, Multi=200 → SL $400 from average. 0 = no Soft SL.
Daily Hard Loss ($)200Daily loss limit. When closed + floating losses reach this — close everything. Resets at midnight UTC. 0 = disabled.
⚠ Soft SL applies to the WHOLE basket (not per position). As grid adds levels, SL shifts to the new average — it may be further away than the initial SL.
